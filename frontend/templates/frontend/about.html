Про проєкт

Навчальний Q&A-сайт як завершена лабораторна робота

Цей варіант поєднує Django REST API, серверно-рендерені сторінки, адаптивну стилістику, профіль користувача та React-віджет, який працює поверх API.

Backend

Django + DRF

API для реєстрації, логіну, профілю, питань, відповідей і голосування.

Frontend

Templates + JavaScript

Серверні сторінки з адаптивною версткою, темою і React-віджетом на головній.

Database

SQLite

Дані зберігаються у локальній базі, а профільні зміни та контент відображаються одразу.

  • Авторизація, профіль та створення нового питання.
